# Практическая работа № 8
## Взаимные блокировки (Deadlocks)

### 1. Алгоритм банкира
Запуск безопасного состояния:
python3 banker.py bank1.txt

Запуск небезопасного состояния:
python3 banker.py bank2.txt

В bank1.txt ожидается безопасная последовательность:
P1 -> P3 -> P4 -> P2 -> P0

В bank2.txt ожидается небезопасное состояние.

### 2. Обнаружение deadlock по журналу событий
Запуск:
python3 deadlock_detector.py events.txt

Журнал events.txt моделирует два процесса, которые удерживают разные ресурсы
и ждут ресурсы друг друга. Детектор должен найти цикл ожидания.

### 3. Отслеживание блокировок
Запуск:
python3 deadlock.py

Программа демонстрирует работу TrackedLock и обнаружение циклического ожидания.

### 4. Обедающие философы
Исправление с упорядочиванием вилок:
python3 philosophers.py ordered

Исправление с ограничением числа философов:
python3 philosophers.py limited

Демонстрация потенциального deadlock:
python3 philosophers.py deadlock

### Контрольные вопросы

1. Почему порядок ресурсов предотвращает deadlock?
Единый порядок захвата ресурсов предотвращает циклическое ожидание.

2. Почему алгоритм банкира редко применяется в обычных ОС?
Он требует знания максимальных потребностей процессов и проверки каждого запроса,
что сложно и накладно при динамическом распределении ресурсов.
