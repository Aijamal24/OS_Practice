## Цель работы

Изучить алгоритмы распределения памяти, сравнить их эффективность и исследовать внешнюю и внутреннюю фрагментацию.

## Используемые алгоритмы

В работе рассматриваются следующие алгоритмы:

- **First Fit** — выбирает первый свободный блок, подходящий по размеру.
- **Best Fit** — выбирает самый маленький свободный блок, в который помещается запрос.
- **Worst Fit** — выбирает самый большой свободный блок.
- **Buddy System** — делит память на блоки размером, равным степени двойки, и объединяет свободные блоки-партнёры.
- **Coalescing (слияние)** — объединяет соседние свободные блоки.

## Вариант A. Сравнение алгоритмов распределения памяти

Исходный размер памяти — 1024 единицы.

Проведено моделирование алгоритмов First Fit, Best Fit и Worst Fit на наборе операций `ops1`.

### Результаты

| Алгоритм | Свободно | Наибольшая дыра | Количество дыр | Отказы |
|---|---:|---:|---:|---:|
| First Fit | 904 | 250 | 5 | 3 |
| Best Fit | 624 | 250 | 5 | 2 |
| Worst Fit | 904 | 250 | 5 | 3 |

### Вывод

Best Fit показал лучший результат на данном наборе операций: он допустил 2 отказа, тогда как First Fit и Worst Fit — по 3.

Отказ может произойти даже при достаточном общем количестве свободной памяти, если нет одного непрерывного свободного блока нужного размера. Это называется **внешней фрагментацией**.

## Вариант B. Слияние блоков и Buddy System

Для сравнения использовался набор из 200 операций `ops2`.

### Влияние слияния свободных блоков

| Режим | Количество отказов | Средняя внешняя фрагментация |
|---|---:|---:|
| Без слияния | 50 | 0.78 |
| Со слиянием | 33 | 0.47 |

### Сравнение четырёх алгоритмов

| Алгоритм | Отказы | Средняя внешняя фрагментация | Средняя внутренняя фрагментация |
|---|---:|---:|---:|
| First Fit + Merge | 33 | 0.47 | 0 |
| Best Fit + Merge | 32 | 0.36 | 0 |
| Worst Fit + Merge | 38 | 0.52 | 0 |
| Buddy System | 38 | 0.36 | 175 |

### Вывод

Слияние соседних свободных блоков уменьшило количество отказов с 50 до 33 и среднюю внешнюю фрагментацию с 0.78 до 0.47.

Best Fit с объединением блоков показал наименьшее количество отказов — 32.

Buddy System уменьшает внешнюю фрагментацию благодаря разделению памяти на блоки фиксированных размеров и их объединению. Однако у него возникает внутренняя фрагментация: выделенный блок может быть больше запрошенного объёма памяти.

## Основные выводы

1. Разные алгоритмы распределения памяти дают разные результаты даже при одинаковых запросах.
2. Best Fit показал лучший результат по количеству отказов в проведённых экспериментах.
3. Слияние соседних свободных блоков помогает уменьшить внешнюю фрагментацию.
4. Buddy System использует разбиение и объединение блоков, но может расходовать дополнительную память из-за округления размера до степени двойки.
