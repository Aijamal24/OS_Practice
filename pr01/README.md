# Практическая работа №1 — Вариант B

## Цель работы

Освоить базовые операции в Ubuntu с пользователями, группами, правами доступа к файлам и каталогам, а также настройку Bash.

В ходе работы необходимо:

* создать второго пользователя `student2`;
* создать группу `developers` и добавить в неё `student2`;
* настроить общий каталог `/srv/shared`;
* проверить создание и удаление файлов с разными правами;
* изучить различия между `su` и `sudo`;
* настроить `.bashrc` с алиасами и переменной окружения.

## Среда выполнения

* Ubuntu 22.04+
* WSL2
* Bash

## 1. Создание пользователя и группы

Был создан пользователь `student2`.

Также была создана группа `developers`, после чего пользователь `student2` был добавлен в эту группу.

Проверка:

```text
student2 : student2 users developers
```

Это означает, что пользователь `student2` состоит в группе `developers`.

---

## 2. Создание общего каталога

Был создан каталог:

```text
/srv/shared
```

Владелец каталога — `root`, группа — `developers`.

Проверка:

```text
drwxrwxr-x 2 root developers 4096 Sep 22 18:37 /srv/shared
```

Права `775` означают:

* владелец `root` имеет права на чтение, запись и выполнение (`rwx`);
* группа `developers` имеет права на чтение, запись и выполнение (`rwx`);
* остальные пользователи имеют права на чтение и выполнение (`r-x`), но не имеют права записи.

Таким образом, участники группы `developers` могут создавать файлы в каталоге, а остальные пользователи не могут создавать или удалять файлы в нём.

---

## 3. Создание и удаление файла

Пользователь `student2` создал файл:

```text
/srv/shared/student2_file.txt
```

Проверка:

```text
-rw-rw-r-- 1 student2 student2 0 Sep 22 19:09 student2_file.txt
```

Владелец файла — `student2`.

Основной пользователь `aijamal` не состоит в группе `developers`:

```text
uname adm dialout cdrom floppy sudo audio dip video plugdev users netdev
```

При попытке удалить файл от имени `aijamal` была получена проверка:

```text
rm: remove write-protected regular empty file '/srv/shared/student2_file.txt'?
```

После ответа `n` файл не был удалён.

Причина заключается в правах каталога. Для удаления файла нужны права записи и выполнения на каталог, в котором находится файл. Пользователь `aijamal` не является владельцем каталога и не входит в группу `developers`, поэтому у него нет права записи в `/srv/shared`.

Важно: право удаления определяется в первую очередь правами на каталог, а не только правами самого файла.

## 4. Разница между `su` и `sudo`

Команда `su` используется для переключения на другого пользователя и запуска оболочки от его имени.

Пример:

```bash
su student2
```

После этого команды выполняются от имени пользователя `student2`.

Команда `sudo` используется для выполнения отдельной команды с повышенными правами, обычно от имени `root`.

Пример:

```bash
sudo mkdir /srv/test
```

Таким образом:

* `su` — переключает пользователя для текущей оболочки;
* `sudo` — позволяет выполнить отдельную команду с повышенными правами.

### Почему прямой вход под `root` в Ubuntu по умолчанию не настроен

В Ubuntu для административных действий обычно используется `sudo`. Прямой интерактивный вход под `root` по умолчанию не настроен, в частности у учётной записи `root` обычно не установлен обычный пароль для такого входа.

Такой подход позволяет выполнять административные действия явно через `sudo` и уменьшает вероятность случайного выполнения обычных действий с максимальными правами.
