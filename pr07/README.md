# Практическая работа №7. Межпроцессное взаимодействие (IPC)

## Цель работы
Изучить FIFO, Unix-сокеты, shared memory и Pipe.

## 1. FIFO
Терминал 1: `python3 fifo_server.py`
Терминал 2: `python3 fifo_client.py`

## 2. Unix-сокеты
Терминал 1: `python3 unix_server.py`
Терминал 2: `python3 unix_client.py "2 + 3 * 4"`

## 3. Shared memory и Pipe
Запуск: `python3 shared_memory_benchmark.py`
Программа сравнивает передачу массива из 10^7 чисел.

## 4. Сравнение IPC
| Механизм | Синхронизация | Объём данных | Особенности |
|---|---|---|---|
| FIFO | Нужна для протокола | Поток байтов | Последовательный обмен |
| Unix-сокет | Нужна для общего состояния | Поток байтов | Несколько клиентов |
| Shared memory | Нужна при совместном доступе | Большие массивы | Быстро, но есть гонки |
| Pipe | Важны порядок обмена и закрытие концов | Поток байтов | Данные копируются |

## Контрольные вопросы
1. Shared memory быстрее для больших массивов, потому что процессы обращаются к общей области памяти без пересылки всего массива. Она опасна без синхронизации: возможны гонки и повреждение данных.
2. Запись в Pipe без открытых читателей вызывает SIGPIPE; если сигнал игнорируется или перехвачен, запись возвращает EPIPE.

## Очистка
Остановить серверы через Ctrl+C. Проверить временные IPC-файлы и `/dev/shm`. Не удалять чужие сегменты общей памяти.
